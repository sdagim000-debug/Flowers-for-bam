# የማይደርቅ አበባ — ASCII flower bouquet

One file: `index.html`. An animated bouquet of flowers drawn with text characters (the flowers rotate and sway), with the Amharic line "የማይደርቅ አበባ" underneath. No build step.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` to the root of the repo.
3. Settings → Pages → "Deploy from a branch" → `main` and `/ (root)` → Save.
4. After a minute, the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Customize
Everything is inside `index.html`: colors in the `COLOR` object, flower positions and rotation speed in the `flowers` array (`spin`).
